# Склад v5.1 Bubble: от первого лица — рохля, тележка, стреппер

Браузерный концепт для телефона. Один файл `index.html` (Three.js с CDN, нужен интернет для библиотеки).
Старые версии: `index_v1.html`, `index_v2.html`, `index_v3.html`, `index_v4.html` (бэкап v4).

Играть онлайн: https://alekseichmsk.github.io/warehouse-game/

## Запуск локально
```
cd warehouse_game && python3 -m http.server 8765
```
Открыть: http://localhost:8765/ — на телефоне: IP компьютера в той же Wi‑Fi сети, порт 8765.

## Что нового в v5 — круглые руки, рохля по деталям, настоящий рычаг
- **Руки круглые**: предплечья-капсулы/цилиндры, скруглённые ладони (RoundedBox), пальцы-капсулы `CapsuleGeometry` со сферическими концами, smooth-материал. Обхват ручки как в v3/v4. GLB в игру не импортируется — руки строятся примитивами Three.js.
- **Рохля по отдельным именованным деталям** (имена = Blender `pallet_jack_parts.glb` = будущие узлы Godot): `Fork_Left`, `Fork_Right`, `Roller_Left`, `Roller_Right` (крутятся при движении, центр на оси), `Body_Hydraulic`, `Pump_Piston` (выдвигается при подъёме), `Steering_Wheel` (группа: поворот вокруг вертикальной оси при рулении + вращение при движении), `Handle_Column` (дышло, поворачивается вместе с рулевым узлом, качается при накачке), внутри неё `Handle_Grip` и `Release_Lever` (анимация нажатия). Деталей намеренно немного — только основные.
- **Пропорции типовой рохли**: общая длина ~1550 мм, вилы 1150×160 мм, ширина по вилам 540 мм, высота опущенных вил 75 мм, рулевые колёса Ø180 мм у насосного узла, ролики вил Ø74 мм, рукоять ~1100 мм.
- **Настоящий принцип управления (по мануалам)**: оператор тянет рохлю за рукоять на себя; дышло жёстко связано с рулевыми колёсами у насоса — повернул дышло вокруг вертикальной оси, на тот же угол повернулся рулевой узел; движение качением от рулевых колёс, вилы — ведомый прицеп следом (в игре корпус доворачивается только в движении, с запаздыванием). Качание дышла = насос. **Рычаг 3 позиции** (кнопка «Рычаг», текущая позиция в HUD): ⬆ ПОДЪЁМ — качаешь, вилы растут; ↔ НЕЙТРАЛЬ — насос отключён, можно везти; ⬇ ОПУСКАНИЕ — удерживаешь рычаг, клапан открыт, вилы плавно вниз пропорционально. Подтверждения «вертикальное дышло = тормоз» в мануалах не найдено — не выдумываем: нейтраль — это позиция рычага, а не дышла.
- **Источники принципа**: Toyota Forklifts, Anatomy of a Hand Pallet Jack — https://www.toyotaforklift.com/resource-library/blog/toyota-products/anatomy-of-a-hand-pallet-jack ; Jungheinrich Profishop, How does a pallet truck work — https://www.jungheinrich-profishop.co.uk/en/profi-guide/how-does-a-pallet-truck-work/ ; Wikipedia, Pallet jack — https://en.wikipedia.org/wiki/Pallet_jack
- **Тележка и стреппер по размерам оригиналов**: тележка-диспенсер ~600×500×1000 мм, бабина Ø420 мм спереди (лицевая), синий ящик сверху ~500×350×250 мм; стреппер ~350×150×180 мм, батарея сзади, рукоять сверху.
- Blender: `/workspace/3d_warehouse/build_pallet_jack_parts.py` → `pallet_jack_parts.blend/.glb/.fbx`, рендеры `pallet_jack_parts.png` и `pallet_jack_parts_exploded.png`. GLB-узлы: Fork_Left, Fork_Right, Roller_Left, Roller_Right, Body_Hydraulic, Pump_Piston, Steering_Wheel, Handle_Column.

## Что было в v3
- **Руки ещё проще + предплечья**: простое предплечье (бокс цвета кожи) от нижнего края кадра + кисть (ладонь-бокс и 5 простых пальцев), без перчаток, без ногтей и деталей. На хвате пальцы почти полностью согнуты вокруг ручки: ладонь сверху, пальцы с одной стороны, большой — с другой, ручка проходит сквозь хват.
- **Поддон — только в пазы**: вилы заходят только в проёмы между блоками-ножками со стороны входа. Нужно выравнивание < ~12°, боковое смещение < ~0.08 м, вилы опущены, рукоять прямо. Пазы подсвечиваются: зелёный — нацелено правильно, красный — рядом, но мимо, серый — далеко. При неверном заходе вилы упираются в блоки (движение блокируется, лёгкая тряска, подсказка «Вилы должны попасть в пазы поддона»). Поддон — твёрдое препятствие, пока вилы не в пазах.
- **Рохля не поворачивает вилами на месте**: на стоянке стиком поворачиваются только рукоять и заднее рулевое колесо, вилочная часть заморожена. Корпус с вилами доворачивается только в движении (вперёд/назад), плавно и с запаздыванием, скорость доворота пропорциональна скорости хода. Развернуть вилы на месте нельзя.
- **Тележка и бабина меньше**: тележка ~0.55 м шириной, бабина Ø ~0.48 м (как реальная катушка стреппинг-ленты). Поддон нормально виден поверх/за тележкой. Тележка по-прежнему подъезжает к поддону лицевой частью — бабиной вперёд, при протяжке бабина раскручивается.
- **Стрелки убраны**: кнопок ◀ ▶ больше нет. Обзор — свайп по правой половине экрана (телефон) и зажатая мышь справа (ПК).
- **Изолон — от рулона, а не по поддону**: большой рулон изолона Ø ~0.5 м стоит рядом с площадкой. Порядок: отмотать полосу от рулона (рулон крутится, полоса тянется) → взять нож и отрезать полосу у рулона (отрезанная полоса отделяется на пол) → положить полосу на поддон → дальше лента и стреппер как раньше.

## Управление
- Телефон: левый джойстик — ходьба / толкать-тянуть объект; свайп по правой половине экрана — обзор; «Взять/Отпустить», жёлтая кнопка — контекстное действие.
- ПК: WASD/стрелки — движение, мышь (зажать справа) — обзор, E — взять/отпустить, Space — действие.

## Этапы
1. Взять рохлю → вилы точно в пазы поддона под стеллажом 2. Качать ручку ×3 3. Вывезти на жёлтую площадку 4. Рычаг вниз, отпустить, отойти 5. Тележку бабиной к поддону 6. Изолон: отмотать от рулона → отрезать ножом у рулона → положить на поддон 7. Протянуть ленту (бабина крутится) 8. Взять стреппер → затянуть. Таймер и очки сохранены.
